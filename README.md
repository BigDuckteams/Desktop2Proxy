# Desktop2Proxy
Инструкция по эксплуатации d2p определителя протоколов подключения для устройств локальной сети:

1. Войдите в профиль через логин и пароль (убедитесь, что они имеются в коде)
-регистрация без логина возможна исключительно для отдельных 'Неизвестных пользователей'

2. Введите IP-адрес устройства, которое желаете найти в сети и нажмите подключиться
-код определит ОС устройства и выведет его в консоль

3. Нажмите кнопку "Обнаружить протоколы" для поиска протоколов, через которые устройства подключены к сети
-По завершении в окно выведет операционную систему устройства и протоколы подключения
-Если устройство не подключено, то будет выдана соответствующая фраза
